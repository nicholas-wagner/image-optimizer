This download is one file. Release builds store jpegoptim, pngcrush, and cwebp inside that file and unpack them before running them. The GUI does not link those programs. It starts each one as its own process.

SPDX-License-Identifier: GPL-3.0-or-later

jpegoptim is free software under the GNU General Public License, version 3 or any later version. The license text follows this notice.

This copy is built from
https://github.com/tjko/jpegoptim/archive/refs/tags/v1.5.6.tar.gz
and is statically linked with libjpeg-turbo 3.0.4, SIMD off, from
https://github.com/libjpeg-turbo/libjpeg-turbo/releases/download/3.0.4/libjpeg-turbo-3.0.4.tar.gz
The build commands are scripts/build-tools.sh on Linux and scripts/build-windows-inner.sh on Windows, in

pngcrush 1.8.13
Copyright (C) 1998-2017 Glenn Randers-Pehrson
Portions Copyright (C) 2005 Greg Roelofs

Image Optimizer change: the PNG_IGNORE_ADLER32 call is wrapped in #ifdef PNG_IGNORE_ADLER32 because libpng 1.6.32 removed that option. This is not the original pngcrush 1.8.13 source. The original notice follows this summary.

pngcrush is built against libpng 1.6.44
https://github.com/pnggroup/libpng/archive/refs/tags/v1.6.44.tar.gz
and zlib 1.3.1
https://github.com/madler/zlib/releases/download/v1.3.1/zlib-1.3.1.tar.gz
On Linux, a system static zlib is used when one is installed. Those licenses ask for an acknowledgment in product documentation and do not require one.
